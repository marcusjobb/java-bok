Här är några ordlistor med vanliga ord och uttryck som används inom IT-världen, tillsammans med korta förklaringar.

## Java

Java är ett programmeringsspråk som utvecklades av Sun Microsystems. Det är ett objektorienterat språk som används för att utveckla olika typer av applikationer, inklusive webbapplikationer, skrivbordsapplikationer och spel.
Exempel på Java-kod:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hej på dig!");
    }
}
```

## Objektorienterad programmering (OOP)

Objektorienterad programmering är en programmeringsparadigm som fokuserar på att organisera kod i objekt som interagerar med varandra. Detta möjliggör återanvändning av kod och underlättar skapandet av komplexa system.
Exempel på OOP-koncept:

```java
public class Person {
private String name;
private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    public String getName() {
        return name;
    public int getAge() {
        return age;
    public void sayHello() {
        System.out.println("Hej, mitt namn är " + name + " och jag är " + age + " år gammal.");
    }

    public class Main {
        public static void main(String[] args) {
            Person person = new Person("Alice", 25); // Who the F*** is Alice?
            person.sayHello();
        }
    }
```

## Kompilering

Kompilering i Java är processen att översätta källkod till bytekod som kan köras på en virtuell maskin. Bytekod är ett mellansteg mellan källkod och maskinkod som gör det möjligt för Java-program att köras på olika plattformar.

## Felsökning

Felsökning är processen att identifiera och åtgärda fel i en applikation. Både C# och Java har inbyggda verktyg och tekniker för felsökning, inklusive användning av felmeddelanden, loggning och avlusning.

## Dokumentation

Dokumentation är en viktig del av programutvecklingsprocessen. Både C# och Java har standardiserade dokumentationsformat, som Javadoc i Java, för att skapa dokumentation för kodbibliotek och API:er.

## Versionshantering

Versionshantering är en metod för att spåra ändringar i källkod över tid. Populära versionshanteringssystem som används med Java inkluderar Git och Subversion. Dessa verktyg möjliggör samarbete och spårning av ändringar i kodbasen.

## Enhetstestning

Enhetstestning är processen att testa enskilda enheter av kod för att säkerställa att de fungerar som förväntat. Java har ramverk för enhetstestning, som JUnit för Java, som underlättar skapandet och körningen av enhetstester.

## API

API står för Application Programming Interface och definierar hur program kan interagera med en viss programvara eller tjänst. Java har stöd för att skapa och använda API:er för att underlätta integration med externa system och tjänster.

## MVC

MVC står för Model-View-Controller och är ett arkitekturmönster som används för att organisera kod i en applikation. Modellen hanterar data och affärslogik, vyn hanterar användargränssnittet och kontrollern hanterar interaktionen mellan modellen och vyn. Java har ramverk som stöder MVC, som Spring MVC för Java.

## SQL

SQL står för Structured Query Language och används för att kommunicera med och manipulera databaser. Java har stöd för att ansluta till och arbeta med databaser med hjälp av SQL.

## Felhantering

Felhantering är processen att hantera och hantera fel som kan uppstå under körning av en applikation. Java har mekanismer för att hantera fel, inklusive undantagshantering med hjälp av try-catch-block och kastning av egna undantag.

## Trådning

Trådning är processen att köra flera trådar samtidigt i en applikation. Java har stöd för trådning, vilket möjliggör parallell och asynkron utförande av kod för att förbättra prestanda och lyhördhet.

## Webbapplikation

En webbapplikation är en applikation som körs på en webbserver och kan nås via en webbläsare. Java har ramverk för att utveckla webbapplikationer, som Java Servlets för Java.

## Mobilapplikation

En mobilapplikation är en applikation som är utformad för att köras på en mobil enhet, som en smartphone eller en surfplatta. Java har ramverk för att utveckla mobilapplikationer, som Android SDK för Java.

## Skrivbordsapplikation

En skrivbordsapplikation är en applikation som körs på en dator och interagerar med användaren via en grafisk användargränssnitt. Java har ramverk för att utveckla skrivbordsapplikationer, JavaFX för Java.

## Ramverk

Ett ramverk är en samling av programvarukomponenter och verktyg som underlättar utvecklingen av applikationer. Java har ett brett utbud av ramverk för olika ändamål, inklusive webbutveckling.
