# Typer

Variabler har olika typer, det är viktigt att veta vilken typ en variabel har för att kunna använda den på rätt sätt.

## Beskrivning

| Typ | Beskrivning |
| --- | --- |
| `char` | En bokstav eller tecken |
| `string` | En sträng av tecken |
| `bool` | Sant eller falskt |
| 'byte' | Heltal med mindre precision |
| `int` | Heltal |
| 'long' | Heltal med högre precision |
| `float` | Flyttal |
| `double` | Flyttal med högre precision |
| 'decimal' | Flyttal med högre precision än double |
| 'DateTime' | Datum och tid |

Här skapar vi en variabel kallad "age" som innehåller värdet 18. Variabeln är av typen "int" vilket betyder att den bara kan innehålla heltal.
