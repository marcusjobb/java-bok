# else if

Else if är kommandot vi använder för att ställa följdfrågor till C-Sharp. Else if är en kombination av else och if. Else if kommer alltid efter ett if eller ett else if. Else if kommer alltid följas av ett if. Else if kommer alltid i slutet av en if-sats.
