# If

If är kommandot vi använder för att ställa frågor till C-Sharp. Frågorna är alltid logiska jämförelser och svaren är alltid sant eller falskt. Om svaret är sant så kommer C-Sharp att utföra det som står efter if. Om svaret är falskt så kommer C-Sharp att hoppa över det som står efter if.

*Filen editerades senast 2022-12-09*
## Exempel

Exemplet ovan skriver om du är myndig om du är 18 eller äldre. Om du är yngre än 18 så kommer C-Sharp att hoppa över det som står efter if.
