# Polymorfism

Polymorfism kommer från grekiskans poly = många och morphe = form. Det är en av de viktigaste egenskaperna i objektorienterad programmering.

## Beskrivning

Polymorfism är en egenskap som gör att objekt som ärver från samma familj av en klass eller ett interface kan hanteras som om de vore samma typ. Detta ger oss möjligheten att skapa en lista av olika objekt från samma familj och ändå kunna hantera dem på samma sätt.
Polymorfism ger oss många fördelar:

- Möjlighet att byta ut delar av programmet utan att behöva ändra resten av programmet.
- Möjlighet att skapa en metod som kan hantera olika typer av objekt utan att behöva skapa en metod för varje typ av objekt.
- Möjlighet att skapa plugins till programmet utan att behöva ändra i programmet, med mera.
