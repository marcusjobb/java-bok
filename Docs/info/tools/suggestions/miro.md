# Miro Board

[Öppna Miro Board](https://miro.com/){: .btn }

## Beskrivning

Miro är en verktyg för att skapa och dela idéer. Det är ett enkelt sätt att samarbeta med andra. Det är enkelt att skapa olika typer av innehåll, som till exempel flödesscheman, wireframes, moodboards, mindmaps, backlog och mycket mer.

Det finns också en mobilapp som gör det enkelt att skriva anteckningar när man är på språng.

Miro har en presentationsläge som kan användas för att presentera skoluppgifter eller projekt.
