# java-bok (forwarder)

Javaboken heter numera **Programmering i Java** och bor på
<https://marcusjobb.github.io/programmering-java/>.

Det här repot innehåller bara redirect-sidor så att gamla länkar till
`https://marcusjobb.github.io/java-bok/…` fortsätter fungera.
Bokens källa: <https://github.com/marcusjobb/programmering-java>.

`generate.mjs` skapar stubbarna från bokens sitemap.
