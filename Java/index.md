# Java

Välkommen till Java världen!

Här börjar din resa i den fantastiska värld som Java erbjuder. Med Java kan man nå många andra operativsystem, fristående maskiner, mobiler och mycket mer. Java är ett av de mest använda programmeringsspråken i världen och det är ett av de mest populära språken att lära sig. Det är ett objektorienterat språk som är enkelt att lära sig och som har en stor community som ständigt utvecklar nya bibliotek och ramverk.

Gör dig redo, ta på dig säkerhetsbältet och låt oss börja!
