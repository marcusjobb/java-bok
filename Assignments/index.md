# Övningsuppgifter

Här finns samlade övningsuppgifter från lektioner och annat. Dessa är tänkta att användas för att öva på olika koncept och för att förbereda sig inför tentor.

Övningarna är uppdelade i kurser:

- **BFU** : Behörighetsgivande förutbildning
- **OOP** : Objektorienterad programmering
- **DA**  : Design och arkitektur
- **Kvs** : Kvaliterssäkring
