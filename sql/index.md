## Vad är SQL?

SQL (Structured Query Language) är ett standardspråk som används för att hantera data i relationella databaser. Det möjliggör att interagera med databaser genom att ställa frågor, lägga till, ändra och ta bort data, samt skapa och hantera tabeller och index. SQL är ett oumbärligt verktyg för att lagra och manipulera data effektivt.

## Skillnader mellan SQL Server, SQLite och MySQL

Här kommer vi att jämföra de tre populära databashanteringssystemen: SQL Server, SQLite och MySQL. Vi kommer att titta på deras egenskaper, funktionalitet och användningsområden för att hjälpa dig att förstå vilket system som passar bäst för dina behov.

### SQL Server

SQL Server, utvecklat av Microsoft, är ett kraftfullt och skalbart databashanteringssystem som är särskilt lämpat för företagsapplikationer och stora databaser. Det erbjuder avancerade funktioner och är väl integrerat med andra Microsoft-teknologier.

### SQLite

SQLite är ett lättviktigt och inbäddat databashanteringssystem som kräver minimal konfiguration. Det är perfekt för mindre applikationer, mobilappar och enheter med begränsade resurser.

### MySQL

MySQL är ett populärt och öppen källkods-databashanteringssystem som är känt för sin snabbhet och skalbarhet. Det används ofta för webbapplikationer och är kompatibelt med olika operativsystem.

## Kommandon och Kategorier

Här följer en tabell som visar olika kommandon inom SQL och deras kategorier:

| Kategori                         | Kommando     | Förklaring                                       |
| -------------------------------- | ------------ | ------------------------------------------------ |
| DDL (Data Definition Language)   | CREATE TABLE | Skapar en ny tabell i databasen.                 |
|                                  | ALTER TABLE  | Modifierar en befintlig tabell.                  |
|                                  | DROP TABLE   | Tar bort en tabell från databasen.               |
| DML (Data Manipulation Language) | SELECT       | Hämtar data från en eller flera tabeller.        |
|                                  | INSERT INTO  | Lägger till nya rader i en tabell.               |
|                                  | UPDATE       | Uppdaterar befintliga rader i en tabell.         |
|                                  | DELETE FROM  | Tar bort rader från en tabell.                   |
| DQL (Data Query Language)        | SELECT       | Används för att hämta data från databasen.       |
| DCL (Data Control Language)      | GRANT        | Ger användare behörighet att utföra operationer. |
|                                  | REVOKE       | Återkallar användares behörigheter.              |
